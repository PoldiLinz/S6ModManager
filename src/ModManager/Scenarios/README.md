# Scenarios & Map Variants

This directory is designed for community map modifications, scenario packs, and custom mission variations.

### Adding New Scenarios:
1. Place any scenario folder (e.g. `my_custom_map`) directly inside this directory.
2. Inside each map folder, create a `scenario.json` and a `map/` subfolder containing `mapscript.lua`.
3. Open the ModManager and navigate to **Maps & Scenario Variants** &rarr; click **Refresh List**.
4. You can also import standalone user-created `.s6map` files using the **"+ Import UserMap as Variant"** button in the ModManager interface.
